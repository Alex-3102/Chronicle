# Chronicle 版本记录

每次发布都通过 `./Scripts/release.sh <版本> <构建号>` 生成 `dist/Chronicle-<版本>.dmg`。

## 1.16 (19) — 2026-11-14

**修复缩小时条目块互相覆盖**

- 根因：条目卡片内部（底色 + 标题文字）有自己的固有高度（约 20pt），外层只给了 `frame(height:)`，没有裁剪，短条目的卡片会被居中撑出边界、盖在相邻条目上，标题也会叠在一起。横竖两个方向都有。
- 修复：卡片填满给定尺寸并在外层 `.clipped()`，内容不再溢出；时间方向放不下标题时（横向 < 44pt、竖向 < 20pt）只留色块，避免文字跨块重叠。
- 顺手修正竖向下轨道标签因宽框居中而错位的问题。

## 1.15 (18) — 2026-11-14

**三轨时间轴 + 横竖双向**

- 时间轴按说明拆成三条轨道：应用（真实活动区间 / 缩小时按主要应用聚合）、项目归属（按时间条目切出的互不重叠 WorkSpan，无覆盖显示未分配）、时间条目（起始边加粗色条 + 标题）。
- 抽出统一坐标层 `TimelineGeometry`：主轴 u 表示时间、副轴 v 表示轨道，绘制、命中测试、悬浮、拖拽共用同一组转换；`pixelsPerHour = (视口主轴长度 − 2 × 留白) / 24 × 缩放`，1 倍时正好铺满一天。
- 支持横向 / 竖向两种方向（头部按钮切换并持久化）：横向刻度在上、三轨自上而下、标签在左；竖向时间自上而下、三轨为三列、刻度在右。文字、图标、卡片始终正常阅读方向，切换时保留视口中心时间。
- 悬浮线贯穿三轨，卡片按真实记录组装；聚合块会额外说明「这一格代表主要应用」。
- 条目可拖拽编辑：边界 7pt 内调整起止、其余移动整条；空白处框选时间范围；按每小时像素分级取整（30/15/10/5 秒），按住 Option 精调到 1 秒；吸附其他条目的真实起止时间，进入 8px / 退出 12px 迟滞。
- 缩放锚点沿用「尺寸与偏移同一次更新」的写法，并扩展到两个方向；实测 20 次连续放大，指针处时间占比恒定不变。

## 1.14 (17) — 2026-11-14

**时间轴缩放改为自托管滚动容器，彻底消除跑位**

- 根因：交给 SwiftUI `ScrollView` 时，内容宽度一改，`NSScrollView` 会先按旧宽度把滚动偏移裁一遍，等下一次事件再纠正——中间那一帧就是用户看到的「位置在移动」。异步补偿无法消除这一帧。
- 改为自托管 `NSScrollView`（`TimelineScrollView` + `TimelineScrollCoordinator`）：内容画布宽度与滚动偏移在**同一次更新**里写入，先算锚点再一次性落位，中间没有可见过渡状态。
- 缩放锚点用捏合双指中点（`magnify(with:)` 的 `locationInWindow`）；按钮 / 快捷键 / 窗口尺寸变化时按可见区域中心锚定。
- 捏合期间吞掉 `scrollWheel`，避免双指移动带动画布横向滚动；非捏合时保留系统原生横向滚动（惯性、方向都不变）。
- 移除上一版的高频补偿逻辑与全局事件监听（`observeTimelinePinch`），悬浮卡片的坐标换算也随之简化。

## 1.14 (16) — 2026-11-14

**时间轴缩放跑位：第二次修复**

- 上一版修复了「重排期间读到旧偏移导致的累积误差」，但真实捏合时双指移动还会带出自带的 `scrollWheel` 事件，横向 ScrollView 被手指带着滚动，叠加在锚定上看起来仍在跑位。新增捏合期间的滚动事件监听，捏合进行中直接吞掉 `scrollWheel` 事件。
- 锚点改用捏合事件的中点（`event.locationInWindow`），而不是鼠标光标位置，更贴合双指操作的直觉。

## 1.14 (15) — 2026-11-14

**时间轴缩放不再跑位**

- 修复连续捏合时锚点越缩越偏：SwiftUI 重排期间 `NSScrollView` 的横向偏移会被按旧内容宽度截断或复位，之前每个缩放事件都读这个中间值，误差会累积。
- 改为由滚动句柄自维护逻辑偏移：缩放事件之间不再读真实偏移，落位后再在随后几帧里持续纠正（内容宽度还没更新时先夹到能滚到的范围，下一帧补上）。
- 缩放结束后才把真实偏移同步回来，之后手动横向滚动仍能接着算锚点；鼠标不在时间轴上时按可见区域中心锚定。

## 1.13 (14) — 2026-11-14

**侧边栏拖拽可以调整同级顺序**

- 拖动项目时按落点实时区分三种结果：行上 1/3 插到该行前面（行上画蓝色横线）、下 1/3 插到该行后面（行下画蓝色横线）、中间 1/3 成为该行的子项目（整行蓝色边框）。
- 改用 `DropDelegate` 实时跟踪指针位置，插入与归属一眼可分，不再只有「归属」一种提示。
- 插入的蓝线从目标层级缩进处开始，与项目树的层级对齐。

## 1.12 (13) — 2026-11-14

**时间轴以鼠标位置为中心缩放**

- 缩放（按钮 / ⌘+ ⌘- / 双指捏合）时以指针所在时刻为锚点：缩放前后鼠标下的时间点保持不动，不再整条时间轴左右漂移。
- 鼠标不在时间轴上时按可见区域中心锚定。
- 悬浮卡片取时刻也改为从底层 `NSScrollView` 换算指针的内容坐标，滚动后仍与可见刻度一致。

**悬浮卡片不再挡住时间轴**

- 卡片固定显示在时间轴下方的「所有活动」区域，横向跟随鼠标、纵向贴着时间轴下沿，不再盖住时间轴本身。

**辅助功能授权判定更准**

- 除了 `AXIsProcessTrusted()`，再实际读一次系统级 AX 属性确认可用，避免系统设置里已授权却仍提示未授权。
- 未授权时每 2 秒复查一次，用户在系统设置里打开开关后提示条自动消失，无需切回应用。

**从本地文件更新**

- 版本号改为直接读取 bundle 里的 `Info.plist`（不再用 `Bundle(url:)`，避免读到进程内缓存的旧版本），弹窗显示「1.11 (12)」这样的完整版本与当前副本路径。
- 按点分段做数字比较（1.11 > 1.9），选择的安装包不比当前版本新时提示「已是最新版本」，不再重复执行安装与重启。

## 1.11 (12) — 2026-11-14

**授权提示改成独立区域**

**统计 / 报告按当前项目展示**

- 侧边栏点击项目不再跳到「活动」tab，停留在当前 tab。
- 统计页按选中项目（含其所有子孙项目）过滤：记录时长、应用使用、项目分布、今日记录都只显示该范围；标题显示「统计 · 项目名」，未分配范围下项目分布显示灰色「未分配」。
- 报告页 7 天数据同样只统计范围内条目，应用使用列按「应用记录 ∩ 范围内条目区间」计算，标题显示「报告 · 项目名」。

**时间轴视觉重做**

- 应用轨道去掉灰色轨道底与文字标签，改为 16pt 细色带：55% 透明度、圆角、不描边，片段够宽时叠放真实应用图标。
- 时间条目改为单行药丸：时钟图标 + 标题 + 时长，6pt 圆角、柔和填充与白色内描边；窄条目只留色块，不再出现「…」；未选中项目的条目整体更淡。

## 1.10 (11) — 2026-11-14

**不再反复弹系统授权窗口**

- 启动时不再调用带提示的辅助功能授权（`AXIsProcessTrustedWithOptions(prompt: true)`），改为静默检查 `AXIsProcessTrusted()`，彻底避免每次启动都弹窗。
- 未授权时在时间轴头部显示提示条：「⚠ 未授权辅助功能 · 去授权 · ×」；点击「去授权」才主动唤起系统授权，点「×」即「不再提醒」并记住选择。
- 从系统设置授权后回到应用自动刷新，提示条随之消失（监听 `didBecomeActive`）。
- 设置页新增「辅助功能权限」：显示已授权 / 去授权；若选择过不再提醒，可点「重新提醒」恢复时间轴提示。
- 说明：辅助功能只用于读取前台窗口标题，未授权时应用使用时长照常统计。

## 1.8 (9) — 2026-11-14

**所有活动改为树形明细（重做）**

- 改成「项目 / 未分配 → 手动计时标题 → 具体时间条目 → 应用 → 网站 / 窗口明细」的展示树，保留项目父子层级；父项目没有直属活动但子项目有时也会展示。
- 同一项目下重复出现的应用合并成一行（优先按 bundle ID，缺失时用应用名）；浏览器按域名显示网站明细，其他应用按窗口标题显示窗口明细。
- 时长口径：节点时长 = 所属活动切片时长之和，`start` / `end` 只表示覆盖范围；父项目 = 直属活动 + 子项目，避免重复累加；应用 / 明细只统计与所属条目重叠的部分。
- 排序：项目、标题、应用、明细按时长降序（同长按稳定 ID），标题下的具体条目按开始时间排序；每个节点使用稳定 ID（`p:` / `t:` / `e:` / `a:` / `d:`）。

**列表外观**

- 改用 macOS 原生 `NSOutlineView` + `NSViewRepresentable`：左侧时长列固定 74pt、右对齐等宽数字，右侧详情列自动伸展。
- 行高 31pt、每层缩进 18pt（`style` / `rowHeight` 会重置缩进与行高，必须在它们之后设置），名称过长省略号，仅纵向滚动。
- 项目显示颜色实心圆点、手动标题显示空心圆环、应用显示真实图标（带缓存）、网站 / 窗口使用符号图标；选中行灰色圆角背景，行间浅色细分隔线。

**交互与刷新**

- 展开收起、键盘导航、多选；双击时间条目打开编辑面板，双击分组展开 / 收起。
- 支持把记录拖到项目（或「未分配」）上完成分配。
- 展开与选中按稳定 ID 保存在视图状态里；刷新时结构相同只更新可见单元格，结构变化才 reloadData 并恢复展开、选中与滚动位置。
- 默认只自动展开项目层级，「未分配」下面是大量零碎应用，保持收起。

## 1.5 (6) — 2026-11-14

**签名与权限**

- 改用固定的本地代码签名证书「Chronicle Local Signing」，不再使用 ad-hoc 签名。ad-hoc 每次构建的 cdhash 都不同，macOS 会把它当成一个全新应用，所以每次更新后辅助功能 / 屏幕录制 / 自动化都要重新授权；改用固定证书后系统识别到的是同一个签名身份，权限可以保留。
- 新增 `Scripts/make-signing-cert.sh`（一次性创建并信任证书），`build-app.sh` 会自动优先使用该证书，找不到时回退 ad-hoc。
- 注意：从 ad-hoc 切到新证书的这**一次**仍会重新授权一次，之后再更新就不会了。
